# 📚 Book Sales Management System

A desktop automation application developed using C# Windows Forms and MS SQL Server, designed to streamline book sales processes and inventory management.

---

## 🛠️ Tech Stack

* **Programming Language:** C# (.NET Framework)
* **User Interface:** Windows Forms (WinForms)
* **Database:** MS SQL Server (`System.Data.SqlClient`)
* **Database Architecture:** Relational Database & Custom SQL Queries

---

## ✨ Key Features

* **Book Management:** Add, update, delete, and list books with status tracking.
* **Customer & Sales Tracking:** Manage customer records and track sales transactions in real time.
* **Inventory Management:** Dynamic stock updates integrated directly with the database.
* **Documentation & Reporting:** Comprehensive technical documentation included.
